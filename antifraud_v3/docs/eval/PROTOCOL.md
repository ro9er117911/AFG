## 這份文件為什麼要在跑任何實驗之前寫完

這是本協定唯一的核心設計。

聲音詐騙偵測這個領域有一段不光彩的歷史（見 §8）。買方對此類產品的預設態度是懷疑，
而懷疑的具體形式是：**「你是先跑了很多組設定，再挑一組好看的報給我嗎？」**

這個問題無法用「我沒有」來回答，只能用**時序**來回答。因此：

- 本文件在取得任何評測結果**之前**寫完並提交至版本控制。
- 假設、資料組成、指標定義、判定門檻、通過/失敗標準，全部在此固定。
- 提交後若需修改，**不得覆寫**，必須在 §9 以修訂記錄追加，載明修改內容、理由、日期。
- 任何未在此預先登錄的分析，在論文中一律標示為 **探索性（exploratory）**，
  不得以確認性結論的語氣陳述。

> 可稽核性優先於效能數字。
> 一個可被第三方重跑並得到相同結果的中等數字，價值高於一個無法查證的漂亮數字。

## 1. 本評測要回答的問題，以及不回答的問題

### 1.1 要回答

| 編號 | 問題 | 對應指標 |
|---|---|---|
| Q1 | Line 2（話術語意偵測）在**電話頻寬**音訊上，區辨詐騙與正常通話的能力如何？ | HTER、FRR/FAR pair、各詐騙類型分項 |
| Q2 | 效能從乾淨寬頻降到電話頻寬時，衰減多少？ | 兩種條件下的 HTER 差 |
| Q3 | 面對 LLM 改寫的詐騙話術，效能衰減多少？ | 改寫強度 vs 準確率衰減曲線 |
| Q4 | within-call 聲學基準（取自通話開頭數秒）是否穩定？ | 同一通話不同視窗的基準值變異 |

### 1.2 明確不回答（同等重要，且會寫進論文正文）

本系統**不宣稱**下列任何一項，本評測亦不試圖證明：

- **不宣稱能測謊。** 聲學特徵不參與風險判定（見 §3），此為刻意設計。
- **不宣稱能判斷情緒真偽或說話者的被操控狀態。**
- **不宣稱單一準確率數字。** 只報 HTER 與 FRR/FAR pair（理由見 §4.1）。
- **不宣稱 Line 1（合成語音偵測）的效能。** 該模型授權不可商用，已排除於本次評測（見 §7.1）。
- **不宣稱在真實營運流量上的表現。** 本評測全部使用離線語料。

## 3. 聲學層為何不參與判定（設計立場，非本次待驗證項）

這是本系統最強的可辯護性論點，且**可用程式碼證明**，不是行銷語言。

`reasoning/fusion.py` 的 `fuse()` 函式簽章只接受兩個判定輸入：

```
fuse(fake_score: float, line2: AntiFraudQwenResult | None, threshold: float)
```

`fake_score` 來自 Line 1，`line2` 來自 Line 2。**沒有任何聲學特徵進入這個函式。**
jitter、shimmer、HNR、F0、eGeMAPS 88 維全部只用於 UI 的描述性呈現。

支持此決定的四條互相獨立的證據：

| 證據 | 結論 |
|---|---|
| DePaulo et al. (2003), *Psychological Bulletin* 129(1), DOI 10.1037/0033-2909.129.1.74 | 116 篇統合分析，158 個線索僅 14 個顯著，平均效果量 d≈0.25 |
| National Research Council (2003) | 語音壓力分析「幾乎沒有科學根據」 |
| Damphousse et al. (2007), NIJ 資助, DOI 10.3886/ICPSR20625.v1 | CVSA 與 LVA 實地驗證準確率約等同擲硬幣 |
| Interspeech 2016 ComParE Deception, DOI 10.21437/interspeech.2016-129 | 官方 baseline UAR 45.1%，低於隨機猜測 |

聲學面板可安全宣稱的只有三句：
1. 「觀察到 F0 相對本通話基準上升」——描述性事實
2. 「語速變慢／停頓增加可能反映認知負荷」——弱陳述
3. 「本面板為 within-call 描述性觀察，不參與風險判定」

## 4. 指標定義

### 4.1 為什麼不報單一準確率

單一準確率數字在本領域是紅旗，不是賣點。Nemesysco 自報 98%、獨立實測約 50%；
AC Global Risk 自稱 97% 但拒絕說明方法論。**報一個漂亮的自報數字，
會讓我們看起來跟他們一樣。**

更技術性的理由：arXiv:2606.21584（"When EER Hides Deployment Failure"）證明，
把來源域的決策門檻直接套到新場景時，**78.7% 的真人語音被誤判**、HTER 達 39.5%，
即使該場景的 EER 讀數看起來只有 11.2%。**EER 是理想門檻下的樂觀數字，
固定門檻部署會有看不見的高誤殺率。**

### 4.2 主要指標

| 指標 | 定義 | 為何選它 |
|---|---|---|
| **HTER** | (FRR + FAR) / 2，在**固定門檻**下計算 | 反映實際部署，不是理想門檻 |
| **FRR / FAR pair** | 兩者同時報，不取單一 | 讓讀者自行判斷哪種錯誤對他們更嚴重 |
| **每類分項** | 依 7 類詐騙類型分別計算 | 整體數字會掩蓋特定類型的系統性失效 |
| **信賴區間** | Wilson score interval，95% | n 小的時候必須顯示不確定性 |
| **operating curve** | FRR/FAR 隨門檻變動的曲線 | 讀者可自選營運點，不被我們的門檻綁死 |

### 4.2.1 為什麼「實驗室 EER」不能當作部署預期（外部證據）

Speech DF Arena（2025）在 **15 個資料集**上評測同一個偵測模型，得到：

| 統計量 | EER |
|---|---|
| 最好的單一資料集 | **0.13%** |
| 平均 | 10.12% |
| pooled | 15.93% |
| 最差的單一資料集 | **31.96%** |

**同一個模型，跨域範圍從 0.13% 到 31.96%——差距 246 倍。**

這是本協定 §4.1「不報單一數字」最有力的外部佐證：任何論文報的同域 EER
（例如 AASIST 在 ASVspoof2019 LA 的 0.83%）都**不能**當作換到新場景後的預期表現。
我方在電話頻寬 + 台灣華語這個從未被任何公開 checkpoint 訓練過的場景上，
必須假設效能落在該分布的差端，而非好端。

這個數字也應該寫進論文——它同時解釋了為什麼我方拒絕報漂亮數字，
以及為什麼買方應該懷疑任何報漂亮數字的廠商。

### 4.3 樣本數與統計效力

**本協定明訂：n < 100 時，不得以「準確率」語氣陳述任何結論。**

參考點：n=8 且全對時，95% 信賴區間下界僅約 63%。也就是說一個真實準確率
只有六成多的系統，也能輕易跑出 8/8。現有 23 個測試音檔遠低於可下結論的門檻。

每個報告的數字都必須同時標示 n 與信賴區間。**沒有 n 的數字不得出現在論文中。**

## 5. 資料集

### 5.1 現有語料的已知限制（實測結果）

執行 `detect_bandwidth()` 於現有全部 23 個音檔：

| 項目 | 實測值 |
|---|---|
| 音檔總數 | 23（13 詐騙 / 10 正常） |
| 總時長 | 10.8 分鐘（平均 28.1 秒） |
| 窄頻（電話頻寬） | **0 / 23** |
| 寬頻 | 23 / 23 |
| 來源 | `edge-tts` 合成語音，非真人 |

**結論：現有語料可驗證 pipeline 端到端接通，不可驗證判別力。**
在建立真人 + 電話頻寬語料前，對外不得引用現有 eval 結果作為準確率。

### 5.2 本次評測要建立的語料

| 語料 | 用途 | 組成要求 |
|---|---|---|
| **A. 公開基準** | Q1，可對照的外部數字 | TeleAntiFraud-28k（授權與可取得性待確認，見 §7.2） |
| **B. 電話頻寬轉換版** | Q2，隔離頻寬變因 | 現有 23 檔經 G.711/Opus 編碼 + 300-3400Hz 帶限。同內容、不同通道條件，可做配對比較 |
| **C. 真人電話錄音** | Q1/Q2，最貼近部署 | 真人語音經真實 PSTN。方法見 `TEST_DATA_ACQUISITION.md`（免費會議橋接，零成本） |
| **D. LLM 改寫對抗集** | Q3 | 由語料 A/B 經 LLM 改寫，多種強度 |

**每一個音檔都必須記錄來源出處（provenance）**——語者是誰、如何取得、
經過哪些處理。出處本身就是可稽核性的一部分。

### 5.3 資料集組成的揭露義務

論文中必須完整揭露每個語料的：語者數、每語者音檔數、時長分布、
真人/合成比例、頻寬條件、詐騙類型分布、標註方式與標註者。

**不得只報「我們測了 N 個檔案」。** 組成決定了數字的意義。

## 6. 通過 / 失敗標準（事前訂定）

事前訂好，才不會事後把任何結果都解釋成成功。

| 項目 | 通過標準 | 未達標時的處置 |
|---|---|---|
| Q1 效能 | 無預設門檻——**這是描述性評測，不是及格考** | 如實報告 |
| Q2 頻寬衰減 | 若 HTER 在電話頻寬下惡化 > 15 個百分點 | 列為部署阻斷項，論文明列 |
| Q3 對抗改寫 | 若準確率衰減 > 30%（對照 Li et al. 的 30.96%） | 列為持續性風險，附監控計畫 |
| Q4 基準穩定性 | 同通話不同視窗的基準值變異 > 20% | 判定 within-call 基準不穩，需加長視窗或降低聲學面板的宣稱強度 |
| 可重現性 | 第三方依本協定可重跑出相同數字（±統計波動） | **這是唯一的硬性通過標準** |

**注意 Q1 刻意不設效能門檻。** 設一個「達到 X% 即通過」的門檻，會製造
調參到剛好過關的誘因。本評測的目的是知道真實效能，不是通過考試。

## 7. 已知阻斷項與限制（主動揭露）

專業買方會自己發現這些。先講建立信任，被抓到損害信任。

### 7.1 Line 1 模型授權不可商用（P0 阻斷項）

`nii-yamagishilab/xls-r-2b-anti-deepfake` 為 CC BY-NC-SA 4.0。
程式碼 `detectors/deepfake_voice.py:4` 自己載明「non-commercial」。
它在 `fuse()` 中是優先序最高的判決來源。

**這是已知的、有解的工程項目，不是隱藏缺陷。** 替代方案評估中。
在更換為可商用 checkpoint 之前，Line 1 不可用於商業部署。

### 7.2 公開基準資料集：可取得，但有三項殘留風險（2026-08-12 調查結果）

TeleAntiFraud-28k **技術上可取得**，可作為語料 A。但三項限制必須寫進論文：

| 項目 | 結果 |
|---|---|
| 授權 | HuggingFace 頁面標示 `apache-2.0`。**但論文正文未對資料集本身聲明授權**，GitHub 的 Apache-2.0 LICENSE 未明確切割「程式碼」與「資料集」。該標籤為上傳者自填 metadata，非法律文件背書 |
| 取得方式 | **Gated（auto-approval）**——需登入 HF 帳號並同意分享聯絡資訊。約 12.7GB，音檔為 MP3 |
| 測試集切分 | **先前記載有誤，2026-08-12 取得資料後實測更正**：官方 `dataset_manifest.json` 顯示 `binary_classification` 為 train 4,000 / **test 400**（實測 fraud 200 / normal 200，完全平衡）。先前記載的 7,021 是 **SFT 任務**的切分（實測其 test 為 6,807）。**詐騙偵測任務的 test 是 400 筆** |
| baseline 數字 | 已確認 **Fraud detection 任務 F1：base 58.51 → fine-tuned 84.78**，同任務可直接對比 |
| **F1 定義** | **未確認是 macro / micro / weighted**——論文未明載。**這代表我方無法保證完全複製其數字** |
| 音訊特性 | **全部經 ChatTTS 重新合成**，連源自真實通話的 DS1 部分也是匿名化後重新生成。**論文未載明取樣率或頻寬規格**，亦無任何電話頻寬模擬敘述 |
| **無逐字稿（2026-08-12 實測）** | 三個切分（`viewer/test.parquet`、`binary_classification.zip`、`sft.zip`）**皆無逐字稿文字欄位**，只有 `audio_path` + `label` + 固定 prompt 模板（`instruction` 欄 nunique=1）。**要測 Line 2 的純文字路徑，必須下載 12.7GB 音訊並自行跑 ASR** |

**對本協定的影響**：

1. 語料 A 可用，但**授權確信度標為「中」**，商業盡調時須註明其法律依據薄弱。
2. **F1 定義未知 → 任何與該論文的數字比較，必須標註為「非嚴格可比」**，
   並同時報告我方自己的 HTER/FRR/FAR（本協定的主要指標不受影響）。
3. **音訊同為寬頻合成語音**——與我方現有語料的限制相同，
   **無法用它回答 Q2（電話頻寬衰減）**。Q2 仍須依賴語料 B 與語料 C。

4. **n 從 7,021 降為 400**（更正）。400 仍遠優於自建語料的 23，且完全平衡，
   足以支撐 §4.3 要求的統計陳述（n≥100）；但**它不是先前以為的那個量級**，
   對外引用時不得沿用舊數字。
5. **必須自行 ASR**：資料集不提供逐字稿，因此我方測到的是
   **「ASR + Line 2」整條鏈路**的表現，不是 Line 2 單獨的表現。
   這與論文 baseline（模型直接吃音訊）**不是同一個受測系統**，
   使「非嚴格可比」的程度比先前記載的更高。

第 3 點很重要：它代表**目前沒有任何公開資料集能回答電話頻寬的問題**。
這既是限制，也再次印證 §7.4 的判斷——真實電話語料是他人同樣沒有的東西。

### 7.3 `DEEPFAKE_FAKE_SCORE_THRESHOLD = 0.85` 未校準

`config.py` 的門檻值未經校準，程式碼已自標 UNCALIBRATED。
Line 1 排除於本次評測，故此項不影響本次結果，但仍為已知未解項。

### 7.4 無台灣在地語料

查無台灣華語／台語深偽偵測資料集，亦查無公開中文詐騙通話逐字稿語料。
**這既是驗證上的困難，也是護城河**——台灣在地語料是競爭者同樣沒有的東西。

### 7.6 Line 1 替代模型：有解，但無捷徑（2026-08-12 調查結果）

授權皆經一手來源（LICENSE 檔／GitHub SPDX metadata）確認：

| 模型 | 授權 | 可商用 | 備註 |
|---|---|---|---|
| `clovaai/aasist` | **MIT**（LICENSE 檔 + SPDX 確認，NAVER Corp.） | **是** | 建議首選。AASIST-L 僅 85K 參數。EER 0.83% 但為 ASVspoof2019 LA **同域** |
| `eurecom-asp/rawnet2-antispoofing` | **MIT**（確認） | **是** | 可作第二架構對照 |
| XLS-R + SLS（QiShanZhang） | **無 LICENSE 檔**，GitHub API 授權端點 404 | **不可推定** | 數字最好（DF 1.92%）但**取得書面授權前不得商用** |
| AASIST3 | **CC BY-NC-ND 4.0** | **否** | 排除。注意其 HF 模型卡標 `cc-by-nc-4.0`、GitHub LICENSE 為 ND 版，**兩個一手來源互相矛盾**，從嚴認定 |
| DeepFense 框架 | Apache-2.0（**僅框架**） | 框架是 | 其 455+ checkpoint 可能各自繼承底層 SSL 模型授權，須逐一查證 |
| Speech-Arena `DF_Arena_100M_V_0` | closed license | **否** | 需個別聯繫索取 |

**關鍵發現：查無任何原生支援 8kHz 電話頻寬的公開 checkpoint。**
無論選哪個底座，微調都不可避免。方法論可參考 ADD-C 基準
（arXiv:2504.12423），該研究專門測試 AMR-WB／EVS／Opus／SILK 等
電信編碼對偵測效能的劣化，並提供資料增強策略。

規劃：以 `clovaai/aasist`（MIT，法律確定性最高）為底座，
在電話頻寬 + 台灣華語語料上微調。**選型以授權確定性為第一準則，
不以論文 EER 數字為第一準則**——因為任何底座都要微調，起點差異會被稀釋，
但授權風險不會。

### 7.5 對抗性風險為持續性，非一次性

Li et al. (2025, arXiv:2507.16291)：GPT-4o 改寫詐騙逐字稿可讓分類器
準確率下降 30.96%。詐騙集團同樣在用 LLM。**這不是可以修好的 bug，
是需要持續監控的風險。** Q3 建立的是基線，不是解法。

## 8. 本領域的歷史脈絡（論文必須主動處理）

買方只要搜尋 "voice stress analysis"，第一頁就會看到：

- **Nemesysco / LVA**：Eriksson & Lacerda (2007) 於 *International Journal of
  Speech, Language and the Law* 14 卷發表〈Charlatanry in forensic speech science〉，
  指其表現接近隨機。2008-12-04 Nemesysco 以誹謗施壓，出版商 Equinox 下架電子版
  ——**從未進入訴訟程序，是法律恐嚇致審查，不是法院認定其有理**。
  獨立驗證（Hollien & Harnsberger 2008；Damphousse et al. 2007-2008）皆測得約 50%。
- **英國 DWP Voice Risk Analysis 試辦**（Nemesysco 技術，24 個地方政府，2007-2010），
  2010 年秋以「不具成本效益」正式終止。官方文件：DWP Research Report No. 716、DEP2010-2071。

**我方與其技術路線的差異必須講清楚**：LVA 屬「黑箱聲壓力推論欺騙意圖」；
我方聲學層完全不參與判決，判定只來自有公開 benchmark 的模型，
且每個特徵的證據等級都標示出來。

正面對照：**Veridas** 通過 iBeta PAD Level 2 獨立合規測試，是可作為後續送測標竿的例子。
**Pindrop** 的 99% 準確率必須標註為廠商自報，不可借用背書。

## 9. 修訂記錄

本協定提交後不得覆寫。所有修改追加於此。

**欄位說明（2026-08-12 修正）**：原本只有一欄「是否在取得結果之後」。
獨立審查指出這個單欄不足以偵測最危險的一種修訂——**換掉受測對象**。
一次修訂可以既不放寬門檻、也不更動指標，卻悄悄把「測的是什麼」換掉，
而在舊欄位下它會被記成無害。因此拆為三欄分別追蹤。

**「只縮小不放寬」是必要條件，不是充分條件**：把受測對象由 A 換成 B
既不是放寬也不是縮小，是**換題目**，不得以「方向是縮小」背書。

### 9.1 分期凍結（v1 結案）

繼續往上表追加修訂，會讓這份預先登錄逐步退化為「有紙本痕跡的事後合理化」。
**分期重新登錄不是失敗，是預先登錄制度的正常用法**：承認某一期的語料回答不了
該期的問題，比把它修訂到面目全非卻堅稱門檻未變誠實得多。

**本協定（v1）於 2026-08-12 結案。** 此後不再追加修訂。

| 問題 | v1 處置 | 理由 |
|---|---|---|
| Q1 鑑別力 | **移出至 v2** | 受測對象已變更為 ASR + Line 2；語料無逐字稿 |
| Q2 電話頻寬 | **移出至 v2** | 天花板效應，且無任何公開語料可回答（§7.2） |
| Q3 對抗改寫 | **保留為 v1 唯一認列結果** | 假設、指標、門檻自登錄起未變，結果有效 |
| Q4 基準敏感度 | **移出至 v2** | 符合條件音檔 n=4，低於自訂 MIN_CLIPS_FOR_VERDICT=8 |

**v1 的可行性檢查失敗，必須記在方法帳上而非全推給語料**：Q2 需要難度足以出錯的
語料，Q4 需要 ≥6 個 chunk 的長通話。現有 23 個 10.8 分鐘合成短音檔**在登錄當天
就能用一次時長統計排除掉**這兩題。這是登錄前未做可行性檢查的失誤，不是運氣不好。

v2 的預先登錄必須包含：受測系統的**完整設定值快照**（§10 的 provenance 欄位，
含 line2_backend／asr_backend／emotion_backend 與模型版本）——v1 只指定了受測
元件，未指定設定值，而「受測系統」實際上是這些設定值的函數。

## 10. 可重現性

論文中每一個數字都必須可由單一指令重新產生。
評測腳本、語料清單（含每檔 checksum）、模型版本、隨機種子全部納入版本控制。

第三方重現所需的一切，必須在不聯絡我們的情況下即可取得——
除了因授權限制無法散布的語料，該情況須明確標示是哪一份、受何限制。

## 11. 結案後的事實更正（2026-08-13）

本協定已於 2026-08-12 結案（§9.1），**內容不得覆寫**。但 §3 的引用表存在一項
事實錯誤，若不更正會持續誤導讀者。依「不覆寫、只追加」原則記錄於此，
原文保留不動。

**§3 引用表第四列的數字是錯的**：

> 原文：「Interspeech 2016 ComParE Deception ... 官方 baseline UAR 45.1%，低於隨機猜測」

經查原始論文 PDF（ISCA archive，DOI 10.21437/interspeech.2016-129）§4.1、§4.3：

| 子挑戰 | development | test baseline | 隨機水準 |
|---|---|---|---|
| **Deception** | 61.1% | **68.3%** | 50% |
| Native Language | **45.1%** | 47.5% | 9.1% |

45.1% 是 **Native Language 子挑戰**（11 類母語辨識）的值，被誤植為 Deception 的
baseline。**Deception 的真實 baseline 高於隨機，不是低於。**

**對本協定結論的影響**：§3 的設計立場（聲學不參與判定）**不受影響**——
其餘三條證據（DePaulo 2003、NRC 2003、Damphousse 2007）與各特徵的證據強度分析
（F0 校正後不顯著、jitter/shimmer/HNR 無一致方向）皆未變動。
但「低於隨機猜測」這個**特別強的措辭不再成立**，論述強度應下修為
「長期低效、未達可部署水準」。

補充的當代數據（2026-08-13 查證）：SVC 2025 Multimodal Deception Challenge
（arXiv:2508.04129，ACM MM 2025）21 隊參賽，跨域測試冠軍 62.44%。
該競賽為 audio+video+text 多模態，**未報告純聲學分模態數字**。

v2 的對應章節（`PROTOCOL_v2.md` §8）已引用更正後的版本。
